# EverPeak Retail Analysis

## Desafío

EverPeak Retail necesitaba analizar datos comerciales para identificar patrones relevantes, valores atípicos y posibles oportunidades de mejora en el desempeño del negocio.

El objetivo del proyecto fue explorar los datos, limpiar inconsistencias y generar hallazgos útiles para apoyar decisiones basadas en información.

## Objetivo del análisis

Este proyecto busca responder preguntas clave como:

1. ¿Qué patrones se observan en los datos comerciales?
2. ¿Existen valores atípicos que puedan afectar el análisis?
3. ¿Qué variables muestran comportamientos relevantes?
4. ¿Qué oportunidades de mejora pueden identificarse a partir de los datos?

## Herramientas utilizadas

- Python
- Pandas
- Jupyter Notebook
- Google Colab
- Limpieza de datos
- Análisis exploratorio de datos
- Visualización de datos
- Tratamiento de valores atípicos

## Proceso

El análisis se desarrolló en varias etapas:

1. Revisión inicial del dataset.
2. Identificación de valores faltantes e inconsistencias.
3. Limpieza y transformación de datos.
4. Exploración de variables principales.
5. Detección de valores atípicos.
6. Aplicación de técnicas para tratar outliers.
7. Visualización de patrones relevantes.
8. Interpretación de hallazgos principales.

## Análisis realizado

Durante el proyecto se exploraron datos comerciales de EverPeak Retail para comprender mejor el comportamiento de las variables principales.

El análisis permitió identificar patrones, revisar la calidad de los datos y aplicar técnicas para manejar valores atípicos antes de generar conclusiones.
